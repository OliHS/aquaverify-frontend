# Checklist — ISO/IEC 17025-ready para laboratorios de agua

URL sugerida: `/es/recursos/checklists/checklist-iso-17025-laboratorios-agua.pdf`

- [ ] Registrar solicitud, cliente, matriz, alcance y prioridad.
- [ ] Vincular muestra con punto, fecha, hora, responsable, transporte y recepción.
- [ ] Documentar método, versión, controles, reactivos, producto y lote.
- [ ] Registrar operador, lectura, incidencias y revisión técnica.
- [ ] Generar CoA con trazabilidad, firma, fecha, versión y estado de publicación.
- [ ] Mantener histórico accesible para auditoría, cliente y seguimiento interno.
