# Checklist — agua en industria alimentaria

URL sugerida: `/es/recursos/checklists/checklist-agua-industria-alimentaria.pdf`

- [ ] Clasificar usos de agua: ingrediente, proceso, CIP, enjuague, hielo, vapor, limpieza o contacto indirecto.
- [ ] Relacionar puntos de muestreo con líneas, lotes, turnos y productos.
- [ ] Definir frecuencia, método, criterios de aceptación y responsable de revisión.
- [ ] Registrar resultado, acción, desviación, investigación y cierre cuando aplique.
- [ ] Preparar evidencia para auditoría interna, cliente, esquemas de calidad o autoridad.
- [ ] Conectar resultados con CoA, histórico y portal cliente si hay laboratorio o servicio externo.
