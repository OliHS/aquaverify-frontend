# Workflow Advisor Maturity Content

Date: 2026-07-07

The maturity enrichment contract requires every maturity dimension to explain:

- what the dimension means in the current workflow
- what to improve first
- how AquaVerify can help
- related modules or capabilities
- the condition before implementation

Spanish visible labels include "Que mejorar primero", "Como puede ayudar AquaVerify", "Modulos o capacidades relacionadas" and "Condicion antes de implantar". The validator checks the localized report object and the synthetic PDF text so raw dimension ids such as `workflow_maturity` do not replace advisory content.
