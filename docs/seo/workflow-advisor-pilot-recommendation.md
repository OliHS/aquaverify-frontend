# Workflow Advisor pilot recommendation

This note documents the pilot recommendation section.

The report now adds `Piloto recomendado` after the improvement plan and before digital modules. The section explains why AquaVerify recommends validating a limited pilot before scaling the full workflow.

Fields:

- Suggested scope
- Indicative duration
- Roles involved
- Evidence to keep
- Expected outcome

For municipal water, the recommended scope is one zone, one tank or a limited set of network points. The pilot should preserve point, date, conditions, custody, method, result, review, CoA and action so the team can test end-to-end reconstruction before expanding dashboards or a portal.
