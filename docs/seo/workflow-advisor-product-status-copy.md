# Workflow Advisor product status copy

The Workflow Advisor no longer uses “No recomendación cerrada” as a visible product status. That wording was internally correct but unclear for buyers because it described what the assessment was not doing instead of what the buyer should do next.

Visible product families now use “Candidato a evaluar · Requiere revisión técnica” in Spanish and equivalent localized copy in EN, FR, IT and CA. The status is used for INDICA, ENUMERA, PLAQUE and ISO/EPA kit families whenever the report can orient a route but cannot close a product recommendation.

The long product text explains that matrix, organism, volume, method, country, laboratory and intended use must be confirmed before treating a family as applicable. It also invites the user to contact AquaVerify water biotechnology experts for a professional, free and no-obligation technical review.

Validation covers the public result, synthetic print/PDF text and CRM Marketing report view. The gate fails if the old wording appears, if a product family lacks the long technical review copy, or if the free technical review CTA is missing.
