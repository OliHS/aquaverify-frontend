# AquaTools Free Architecture

## Scope

AquaTools Free adds a public calculator hub and eight indexable calculator pages to the corporate site:

- dilution
- molarity
- laboratory unit conversion
- RPM/RCF conversion
- CFU/UFC
- recovery, bias and RPD
- hardness and alkalinity as CaCO3
- chemical species and nutrient forms

The public pages run without registration, calculate in the browser and keep saved records, history, ELN, LIMS review, traceability and collaboration inside AquaVerify Cloud.

## Calculation Source

The canonical calculation source remains AquaVerify Cloud. The corporate repository vendors a deterministic browser/Node artifact in `vendor/aquatools-core`.

The artifact is produced by the Cloud script:

```bash
npm run sync:aquatools-core
```

The corporate verifier checks the vendor manifest and SHA-256:

```bash
npm run verify:aquatools-core
```

Manual formula edits in the corporate site are intentionally avoided. UI copy, SEO copy and routing live in the corporate site; formulas and acceptance vectors live in the shared core artifact.

## Runtime Rendering

Runtime pages are selected through the existing marketing route system:

- `utils/aquatoolsRoutes.js` defines the 45 localized URLs.
- `utils/aquatoolsContent.js` defines localized copy, metadata, FAQ, formulas, examples and related links.
- `pages/marketing-routes/AquaToolsMarketingRoute.tsx` dispatches hub/tool pages.
- `components/aquatools/AquaToolsHubLanding.tsx` renders search and category filtering.
- `components/aquatools/AquaToolPage.tsx` renders the localized SEO page.
- `components/aquatools/AquaToolFormShell.tsx` runs the browser calculation.

The form imports `calculateAquaTool` from `vendor/aquatools-core/index.js`. It does not call `fetch`, XHR or `sendBeacon` and only emits a local browser event without input values or results.

## Prerender And SEO

Static HTML is generated by `scripts/prerender-marketing-pages.js`. AquaTools pages include:

- one H1
- canonical URL
- hreflang and x-default alternates
- robots index/follow
- visible formula, variables, worked example, warnings, privacy and disclaimer
- FAQPage JSON-LD
- ItemList schema on the hub
- WebApplication schema on calculator pages

The sitemap group is `public/sitemaps/sitemap-tools.xml`, generated by `scripts/generate-sitemap.js`.

## Validation

Source checks:

```bash
npm run validate:aquatools:source
```

Dist checks after build:

```bash
npm run build
npm run validate:aquatools:dist
```

The validator checks the eight approved tools, the 45 localized routes, privacy/disclaimer copy, JSON-LD, formula/example presence and all shared acceptance vectors.
