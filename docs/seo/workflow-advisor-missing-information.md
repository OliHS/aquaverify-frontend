# Workflow Advisor missing information

This note documents the missing information section.

`missingInformation` is now structured as cards instead of plain strings. Each item includes:

- Pending data
- Why it matters
- Who should confirm it
- How to use it in review

The design avoids repeated "why it matters" text. Examples include exact method or reference, concrete water matrix by use, priority organism, real sample volume, intended use, responsible laboratory and review criteria.

The section helps the buyer understand what must be clarified before closing analytical route, product evaluation, document requirements or implementation scope.
