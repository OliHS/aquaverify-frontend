# Workflow Advisor premium result

This note documents the premium result changes in the Workflow Advisor report.

The report now presents priority problems as specific operational narratives. Each selected problem includes a localized title, explanation, operational impact, improvement focus, AquaVerify support, related capabilities, and next step.

The municipal scenario explicitly covers:

- Coordinar muestreo de red
- Gestionar incidencias y remuestreos
- Preparar registros para el Plan de Seguridad del Agua

The result also adds two consultative sections:

- `Piloto recomendado`
- `Nivel de detalle del diagnóstico`

The report remains a consultative workflow report. It does not present a compliance score or close a product decision without method, matrix, volume, country, intended use and laboratory review.
