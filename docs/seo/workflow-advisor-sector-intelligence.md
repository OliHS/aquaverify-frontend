# Workflow Advisor Sector Intelligence

Workflow Advisor V2 incluye perfiles sectoriales para los 9 sectores del cuestionario:
- laboratorios de analisis de agua
- control de calidad del agua
- agua municipal
- alimentacion y bebidas
- agua de proceso industrial
- riesgo de agua en instalaciones
- agricultura
- pharma y cosmetica
- hosteleria, turismo y ocio

Cada perfil define:
- titulo y subtitulo de informe por idioma
- contexto de comprador
- objetos de evidencia del sector
- riesgos comunes
- roadmap recomendado
- recursos sectoriales, glosario y herramientas relacionadas

Cuando un roadmap no esta escrito manualmente en un idioma, el core genera una hoja de ruta localizada generica en ese idioma. No se muestra fallback visible en ingles para FR, IT o CA.

La inteligencia sectorial vive en el core compartido para que corporate, CRM y API produzcan el mismo resultado.
