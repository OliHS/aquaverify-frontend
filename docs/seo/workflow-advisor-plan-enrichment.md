# Workflow Advisor Plan Enrichment

Date: 2026-07-07

The plan enrichment contract turns each improvement phase into a consultative step with:

- objective
- actions
- related modules
- products to evaluate when applicable
- what to define before implementation
- expected operational outcome
- next step

Digital modules inside the plan must expose the related phase, problem solved, required data, operational outcome and implementation condition. CRM is not a visible client module, and AquaTools must not be promoted as a primary digital module when the recommendation is not a calculation workflow.
