# Workflow Advisor resource links

This note documents related resource links in the Workflow Advisor report.

Each resource now includes:

- Title
- Description
- URL
- Type label: industry, glossary, resource, tool or platform

Municipal reports can include the municipal water industry page, AquaVerify Cloud, CoA glossary, digital chain of custody glossary, Water Safety Plans resource, RD 3/2023 resource and ISO 19458 sampling reference.

The report must not link related resources back to the diagnostic landing page. Resource links support technical review and next reading, not circular navigation.
