# Workflow Advisor CRM Report V2

El CRM Marketing lee `analysis_snapshot_json.reportV2` cuando existe. Para assessments historicos, reconstruye el informe V2 desde scores, recomendaciones y respuestas guardadas.

Vista de detalle:
- Informe consultivo
- Respuestas
- Reglas
- PDF
- CRM / Lead

La pestana PDF muestra:
- filename esperado
- modo `dedicated-print`
- fecha `generatedAt`

El objetivo del CRM es revisar el informe consultivo que vio o pudo ver el comprador, sin depender del JSON tecnico ni de IDs internos.
